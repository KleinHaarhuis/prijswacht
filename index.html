Instellingen

Iedereen met de link kan je lijst bekijken. Om op dit toestel producten toe te voegen of aan te passen is een toegangscode van GitHub nodig. De code blijft alleen op dit toestel staan.

  1. Ga op github.com naar Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Kies Generate new token en geef alleen toegang tot het project van deze app.
  3. Zet bij Repository permissions het onderdeel Contents op Read and write.
  4. Kopieer de code en plak hem hieronder.
