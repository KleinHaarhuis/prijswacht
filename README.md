# Prijswacht

Een kleine app die prijzen volgt van producten in winkels in Nederland, België en Duitsland.

- `index.html`, `sw.js`, `manifest.webmanifest`: de app zelf. Hij draait op GitHub Pages en is te installeren vanuit de browser.
- `data/products.json`: je lijst met producten, gevonden prijzen en het prijsverloop. Claude werkt dit bestand dagelijks bij.

## Aanzetten

1. Ga in dit project naar Settings, Pages.
2. Kies bij Source voor "Deploy from a branch", branch `main`, map `/ (root)`.
3. Open na een minuut het adres dat GitHub toont en kies in je browser "Installeren" of "Toevoegen aan startscherm".

Producten aanpassen in de app kan nadat je bij Instellingen een toegangscode van GitHub hebt ingevuld.
